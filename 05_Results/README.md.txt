# Results

This directory contains the scientific interpretation and discussion of all DFT and TD-DFT calculations performed on Curcumin_3OH.

Included analyses:

- Geometry Optimization
- Frequency Analysis
- HOMO–LUMO Analysis
- Global Reactivity Descriptors
- TD-DFT UV–Vis Analysis

The files in this directory summarize the key findings obtained from the quantum chemical calculations performed using ORCA.
