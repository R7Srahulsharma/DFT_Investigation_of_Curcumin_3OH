# References

This directory contains bibliography and citation files associated with the computational investigation of Curcumin_3OH.

## Included Files

### opt.bibtex

BibTeX file automatically generated by ORCA during quantum chemical calculations.

The file contains references related to:

- ORCA quantum chemistry package
- Density Functional Theory (DFT)
- TD-DFT methodologies
- RIJCOSX approximation
- Integral evaluation algorithms
- Electronic structure calculations

## Citation Policy

Researchers using this repository are encouraged to cite the original ORCA publications and methodological references provided in the BibTeX database.
